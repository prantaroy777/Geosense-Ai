# Changelog

## 0.4.0a1

- Prepare the first public experimental source release with an MIT code license,
  contributor guidance, CI, reproducible release tooling and clean-install checks.
- Unify application and export version metadata.
- Harden saved-run metadata, upload filenames and raster input validation.
- Escape spreadsheet formulas in exported CSV labels.

Existing capabilities include bounded GeoTIFF processing, spectral candidate
screening, GIS vector package import, presentation exports, coverage-aware
vector monitoring and a checksum-verified local run library. Scientific accuracy
remains unvalidated; provider classifications are preserved as provider evidence.
